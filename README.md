
# General Database Management Application

## Project Description
A Python application that manages data
using an SQLite database.

## Features
- Create Database
- Insert Records
- View Records
- Search Records
- Update Records
- Delete Records

## Technologies Used
- Python
- SQLite3

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command:

   python main.py

## Database
SQLite is used for permanent data storage.
